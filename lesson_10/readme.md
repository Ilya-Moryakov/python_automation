# Автоматизация тестирования с Allure-отчетами (Урок 10)

В данном проекте реализованы UI-тесты с использованием паттерна проектирования **Page Object Model (POM)**, аннотацией типов и интеграцией фреймворка репортинга **Allure**.

## Предварительные требования

1. **Python 3.10+** должен быть установлен в системе.
2. Установлен **Allure CLI** для генерации и просмотра отчетов локально:
   - Для **macOS**: `brew install allure`
   - Для **Windows** (через Scoop): `scoop install allure` или скачайте архив с [официального репозитория](https://github.com) и добавьте путь к бинарному файлу в переменные окружения `PATH`.

## Установка зависимостей

Перед запуском установите необходимые библиотеки:

```bash
pip install pytest selenium allure-pytest
```

## Запуск тестов и формирование отчета

Для запуска тестов с автоматическим сбором результатов для Allure выполните команду:

```bash
pytest --alluredir=allure-results
```

*Папка `allure-results` создастся автоматически и будет содержать сырые JSON-данные.*

## Просмотр сформированного отчета

Чтобы сгенерировать графический HTML-отчет во временной папке и автоматически открыть его в браузере, выполните:

```bash
allure serve allure-results
```

Если вам нужно просто сгенерировать статическую папку с HTML-отчетом:

```bash
allure generate allure-results -o allure-report --clean
```
